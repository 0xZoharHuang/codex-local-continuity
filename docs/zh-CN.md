# 在同一台 Mac 上沿用本地项目

Codex 切换账号后，本机聊天可能仍然能打开，侧栏却只剩一列聊天。这个工具在桌面 App 完全退出后，给你选定的本机身份对齐项目分组。还可以单独启用输入历史，让原生输入框的 ↑ 找回同一条本地聊天中另一个身份发过的纯文本。

## 先预览，再决定范围

在仓库目录运行：

```sh
/usr/bin/python3 -I -B src/manage.py profiles
/usr/bin/python3 -I -B src/manage.py preview --profiles existing
```

`existing` 只纳入现在已经初始化的身份。`all` 也会自动纳入以后登录的身份。也可以用 `profiles` 显示的两个或多个本机标签，用英文逗号隔开。个人与公司工作区共用一台电脑时，应先选定允许共享本地项目名称、目录和分组的范围。

```sh
/usr/bin/python3 -I -B src/manage.py install --profiles existing
```

默认只同步分组。希望共享输入原文时，在预览和安装命令末尾添加 `--include-history`。输入可能包含私人资料，过滤器只能识别部分凭据或引用。首次合并保留各身份已有顺序；单条聊天最多保留 20 项。切号后如果想看到刚才的修改，正常退出再重开 Codex。

使用 `status` 查看最近一次结果。`uninstall` 卸载监听器并保留私有恢复点。要撤回最近一次同步，先退出 Codex，再运行 `restore`。若相关值后来被改过，工具会停止恢复，避免覆盖新修改。备份中可能有旧输入原文，请勿公开配置、数据库、会话文件或备份。

工具不登录账号，不调用模型。模型列表、额度、插件授权和定时任务调度受相应服务和工作区规则约束。详见[功能与账号的关系](account-boundaries.md)和[验证方法及已知边界](verification.md)。

## 用设置面板调整范围

在 Finder 双击仓库里的 **settings.command**，按 L 可切换中英文；也可以在终端运行：

```sh
/usr/bin/python3 -I -B src/manage.py settings --lang zh
```

如果只想让两个账号认得同一批本地目录，选 `folders`；再加同聊天的 ↑ 则选 `folders-history`。原生界面仍可能按工作目录显示已有聊天，但工具不会搬运你的手工归属或明确排除。完整项目分组选 `projects`，仅 ↑ 选 `history`，两者选 `both`，暂停选 `off`。保留当前身份组时无需重新输入标签。保存设置可以在 Codex 开着时进行，下一次正常退出才处理原生数据。改小范围不会撤回之前已经复制到目标身份的文字；将该目标加入新组时，它已有的输入也可能被新组成员看到。需要撤回上一笔同步时，应先恢复，再更改范围。

遇到「换号后插件或定时任务少了」时，在 A 下执行 `doctor baseline`，切到 B 后执行 `doctor compare`（前缀同上）。先看身份是否实际改变，再看本地定义差异；还需在 B 的原生界面核实权限或查看自然运行结果。所有检查都由你手动运行。用 `capabilities --lang zh` 可以查看各项由哪里管理。
